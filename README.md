# Train Defense

TypeScript · Canvas 2D · Vite로 만든 열차 디펜스 게임입니다. 본편과 기관차 비교 데모를 포함합니다.

## 실행

Node.js와 npm이 설치된 환경에서 실행합니다.

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

터미널에 표시된 주소에서 다음 페이지를 엽니다.

| 경로 | 내용 |
| --- | --- |
| `/` | 본편 — 36웨이브 |
| `/demo.html` | 약 10~12분 기관차 비교 데모 |
| `/sounds.html` | 효과음·배경음악 도감 |
| `/showcase.html` | 열차·몬스터·전장 쇼케이스 |

## 데모 체험

표준 기관차 → 정찰 기관차 → 공성 기관차 순서로 같은 개조 경로와 칸 배치를 비교합니다. 세 기관차는 같은 맵·적 배치·시작 편성·개조 선택지를 사용합니다.

- Q: 짧은 가속. 부착 적을 떼어냅니다.
- E: 감속하며 집중사격. Q/E는 재사용 대기시간을 공유합니다.
- F 또는 오른쪽 클릭: 우선 표적 지정.
- 클릭: 주포. 방향키로 조준 후 Space/Enter로도 발사합니다.
- Esc: 일시정지.
- 3·6·9구간 뒤 개조 선택 → 지원칸을 포함한 편성 재배치 → 출발.
- 각 구간 제한은 105초이며, 마지막 구간은 그람 보스전입니다.

기관차별 최근 결과에는 남은 코어, 누적 피격, 차단 수, 시간과 개조 경로가 표시됩니다. 데모 결과는 해당 브라우저에만 저장됩니다.

## 빌드 및 전달

```sh
npm run build
npm run preview -- --host 127.0.0.1
```

빌드 결과인 `dist/`를 정적 웹 호스팅의 루트에 올리면 실행됩니다. HTML을 파일로 더블클릭하지 말고 웹 서버로 실행해야 합니다. `127.0.0.1` 주소는 실행 중인 컴퓨터에서만 접속할 수 있습니다.

## 선택 사항: 온라인 랭킹

환경설정 없이도 게임과 데모를 실행할 수 있습니다. 본편의 온라인 랭킹을 연결하려면 `.env.example`을 `.env`로 복사하고 본인 Supabase 프로젝트 설정과 `td_ranking` 테이블·접근 정책을 구성하세요. 공유 저장소에는 운영 환경설정이 포함되지 않습니다.
